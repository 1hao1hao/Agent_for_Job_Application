# 用户画像

## 求职目标

1. 目标岗位：大模型应用研发实习生、AI 应用开发实习生、后端研发实习生。
2. 目标地区：广州、深圳、上海、杭州，也接受远程实习。
3. 希望项目能体现工程能力、测试意识、可观测性和效果评测能力。

## 当前准备重点

1. 构建一个面向实习求职场景的多源 RAG/Agent 系统。
2. 准备每个模块的面试讲解，包括输入、输出、核心函数和失败排查。
3. 避免过早复杂化，先完成最小可运行版本，再做 LangGraph 或 LlamaIndex 重构。

## 偏好

1. 回答要尽量结合岗位 JD 和个人简历。
2. 当证据不足时，系统应该说明不确定，而不是编造经历。
3. 评测结果必须来自真实测试或人工标注，不能伪造。
