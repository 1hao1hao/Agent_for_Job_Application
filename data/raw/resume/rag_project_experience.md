# RAG 项目经历候选记录

候选人设计了多源 Document 与 Chunk Schema，支持岗位、简历、面试笔记、项目日志和用户画像。系统包含规则 Router、关键词 Retriever、预算感知 Context Builder 和 Citation Validator。

项目使用 JSONL Trace 保存路由、召回、生成、校验与耗时，并使用 Fake LLM 完成离线集成测试。
